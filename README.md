# 四诊体质自测系统 PWA

基于国标《中医体质分类与判定》(ZY/T 001.1-1994) 的中医体质自测工具。

## 功能

- 四诊合一测评：望诊（舌象面色）+ 闻诊（口气气息）+ 问诊（61题国标问卷）+ 切诊（脉象）
- 智能报告生成：体质判定 + 脏腑倾向 + 饮食/作息/运动三维调养建议
- PWA离线支持：可安装到手机桌面，断网可用
- 隐私友好：数据仅存储于本地，不上传任何服务器

## 技术栈

- 纯前端（HTML + CSS + JavaScript）
- PWA（Service Worker + Web App Manifest）
- 部署平台：Netlify

## 使用

直接打开 `index.html` 即可使用，或访问在线版本。

## 开发

```bash
# 本地预览
python -m http.server 8000
# 或
npx serve .
```
